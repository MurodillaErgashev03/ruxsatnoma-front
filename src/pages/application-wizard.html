Уберите пересечение 3,2 га — тогда шаг можно завершить
Решения, принятые на этом экране.
  • Карта занимает основную площадь, панель — 360px справа. Участок выбирают глазами, а не из выпадающего списка: иерархия область → район → лесхоз → лесничество → обход → квартал → контур остаётся доступной, но она вторична.
  • Пересечение вычислено, а не нарисовано. Полигон соседнего разрешения обрезан контуром через clipPath — так же, как ST_Intersection сделает это на сервере. Рядом сказано, какое разрешение занимает участок и до какой даты.
  • Занятость читается без цвета. Штриховка, сплошная красная граница, подпись на карте, строка «− Занято 3,2 га» в панели и текст ошибки — пять носителей одного смысла, WCAG 1.4.1.
  • Расчёт показан цепочкой. Пользователь видит урожайность, площадь, долю сезона, страховой фонд и норму корма со ссылкой на источник каждого значения — требование воспроизводимости п. 4.2.15 ТЗ. Число без расшифровки порождает обращение в поддержку.
  • «Далее» заблокировано, но объяснено. Кнопка помечена aria-disabled и связана через aria-describedby с причиной; главное действие вынесено в сообщение об ошибке.
  • Границы всех элементов управления — neutral-500. neutral-200 остаётся только на декоративных разделителях: его контраст 1,24 при требуемых 3,0 по WCAG 1.4.11.
